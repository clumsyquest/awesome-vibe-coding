# Contribution Guidelines

First off, thank you for considering contributing to `awesome-vibe-coding`! 🎉
This list is maintained by the community, for the community.

## How to contribute

To ensure this list remains a high-quality resource for the Vibe Coding era, please make sure your pull requests adhere to the following guidelines:

1. **Search prior submissions:** Please make sure the tool/framework hasn't already been added.
2. **Relevance is key:** The tool must be specifically useful for AI-assisted software engineering (Vibe Coding). Generic developer tools that don't have a strong AI angle should not be included.
3. **Quality over quantity:** We prefer well-maintained, high-quality projects. If it's a GitHub repo, it should generally have a decent amount of stars/activity.
4. **Alphabetical order:** Please keep the items in alphabetical order within their respective categories.
5. **Format:** Use the exact format of the existing list: `* [Tool Name](Link) - Short, punchy description.`

## Step-by-Step

1. Fork the repository.
2. Create a new branch: `git checkout -b add-my-awesome-tool`
3. Add your entry to the `README.md`.
4. Commit your changes: `git commit -am 'feat: add [Tool Name]'`
5. Push to the branch: `git push origin add-my-awesome-tool`
6. Submit a Pull Request!

Thank you for helping build the standard stack for the Vibe Coding generation! 🌊
