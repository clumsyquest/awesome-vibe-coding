## 💻 AI IDEs & Editors

* [Cursor](https://cursor.com/) - The AI Code Editor built to make you extraordinarily productive. A fork of VS Code tailored for AI pair programming.
* [Windsurf](https://codeium.com/windsurf) - The world's first agentic IDE by Codeium.
* [Zed](https://zed.dev/) - High-performance, multiplayer code editor written in Rust. Fast and AI-ready.
* [PearAI](https://trypear.ai/) - Open-source AI code editor, transparent and community-driven.

## 🤖 Autonomous Agents & CLI

* [Claude Code](https://code.claude.com/) - Anthropic's terminal-based AI assistant that writes code, runs commands, and interacts with your repo.
* [Aider](https://aider.chat/) - AI pair programming in your terminal. Works beautifully with Git.
* [Devin](https://cognition.ai/) - The first autonomous AI software engineer.
* [Cline](https://github.com/cline/cline) - An autonomous coding agent right inside your IDE.

## 🛡️ Security & AI Governance

* [Axyr](https://axir.dev/) - The deterministic AI Change Safety Layer. Built in Rust to instantly catch business logic flaws (IDOR, SSRF) in AI-generated code with zero false positives.
* [Semgrep](https://semgrep.dev/) - Fast, open-source static analysis for finding bugs and enforcing code standards.
* [Gitleaks](https://github.com/gitleaks/gitleaks) - Fast, light-weight, open-source secret scanner to protect keys from being pushed by AI.

## ⚡ Next-Gen Frameworks & BaaS

* [Next.js](https://nextjs.org/) - The React Framework for the Web. The default choice for modern full-stack AI apps.
* [Supabase](https://supabase.com/) - The open-source Firebase alternative. Instant Postgres, Auth, and Edge Functions.
* [Convex](https://www.convex.dev/) - The reactive backend for modern web apps. Replaces your database, server, and state management.
* [Elysia](https://elysiajs.com/) - Ergonomic Framework for Humans. Ultra-fast Bun web framework.

## 🧠 LLM Orchestration

* [Vercel AI SDK](https://sdk.vercel.ai/) - The TypeScript library to build AI web apps. Stream text and generate UIs easily.
* [LangChain](https://langchain.com/) - Framework for developing applications powered by language models.
* [LlamaIndex](https://www.llamaindex.ai/) - Data framework for connecting custom data sources to large language models.
* [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) - An open standard that enables AI models to securely connect to local and remote data sources.

## 🚀 Deployment & Infrastructure

* [Vercel](https://vercel.com/) - The platform for frontend developers, providing the speed and reliability innovators need.
* [Railway](https://railway.app/) - Infrastructure, without the headache. Deploy code instantly.
* [Cloudflare Workers](https://workers.cloudflare.com/) - Build serverless applications and deploy globally across the Cloudflare network.
